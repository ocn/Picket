# Keep contract monitoring public and structure-only

Contract intelligence will use public regional contract observations plus the existing operator-managed `esi-universe.read_structures.v1` authorization for accessible player-structure location enrichment. It will not request character or corporation contract-history scopes or add authorization commands, profiles, or UI because the tracked adversarial contracts do not involve the operator's character, corporation, or alliance; those scopes therefore cannot reveal their Acceptors. Live enrichment is synchronous before initial delivery, unavailable optional facts are omitted, and posted messages are not dynamically rerendered. Historical rerender remains an explicit bounded operator migration that reuses retained evidence to bring existing messages to the current format.
